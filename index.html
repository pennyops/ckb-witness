ckb-witness: public CKB RPC agreement monitor

Each hourly run asks every keyless public CKB mainnet RPC for its tip, then compares the block hash at a common height (tip - 12), then looks up the newest transaction of that block on every endpoint (all should report it committed in the same block). Disagreement or a lagging endpoint means a user who trusts that single endpoint could see a stale or different chain view. Source and raw log: github.com/pennyops/ckb-witness (measurements.log). Anomaly events (disagreement, lag, endpoint down, tx mismatch, indexer lag) as an Atom feed: feed.xml.
